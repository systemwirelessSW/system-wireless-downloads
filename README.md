# System Wireless for Windows

[Download System Wireless](https://github.com/systemwirelessSW/system-wireless-downloads/releases/latest/download/System-Wireless-Setup.exe)

Download the installer, open it, and launch System Wireless. Sign in with the application account and password supplied privately by your company owner. The server connection is already configured. No GitHub account or developer tools are required.

Version 0.4.2 is an **unsigned pilot** for 64-bit Windows. Windows or your company's endpoint security may flag or block installation. Use a company-signed release for routine rollout; do not disable endpoint protection. Automatic updates are not configured: download newer installers from this same link.

Internet access is required to sign in and confirm transactions. Drafts save locally. Check Cloud Sync before re-entering a pending transaction. Validate device encryption, printers/scanners, and your existing accounting process during the pilot.

This repository hosts installers and public instructions. It contains no company database, application passwords, or deployment credentials. Installation does not grant access to company data.

Version 0.4.1 fixes startup beside an earlier local installation. Local records are preserved in place and are not automatically imported into the separate cloud workspace. Install the update over the existing application.

Version 0.4.2 improves logo lettering contrast on dark backgrounds.
